# Console Calculator

A simple yet robust console calculator built in C++ as a learning project.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, division
- Input validation — handles non-numeric input gracefully
- Division by zero protection
- Unknown operator handling
- Loop mode — perform multiple calculations in one session

## How to Run

1. Clone the repository:
```
   git clone https://github.com/JSairanbayev/cpp-calculator.git
```
2. Compile:
```
   g++ calculator.cpp -o calculator
```
3. Run:
```
   ./calculator
```

## Example
```
=== Console Calculator ===

Enter first number: 10
Enter operation (+, -, *, /): /
Enter second number: 3
Result: 10 / 3 = 3.33333

Continue? (y/n): n
Thank you for using the calculator!
```
